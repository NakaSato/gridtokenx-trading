## 2. Logo Guidelines

### 2.1 Primary Logo

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│    ⚡ GRIDTOKENX                                            │
│                                                             │
│    [Icon + Wordmark horizontal lockup]                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Usage:** Primary brand representation on websites, apps, marketing materials

### 2.2 Logo Variations

| Variation | Use Case | Format |
|-----------|----------|--------|
| **Primary** | Light backgrounds | Full color |
| **Reverse** | Dark backgrounds | White |
| **Icon Only** | Favicons, app icons, social | Full color |
| **Monochrome** | Single-color print | Black/White |
| **Vertical** | Square spaces, badges | Stacked |

### 2.3 Clear Space

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│         ┌─────────────────────────────────┐                │
│         │                                 │                │
│         │    ⚡ GRIDTOKENX                │                │
│         │                                 │                │
│         └─────────────────────────────────┘                │
│              ↑                           ↑                 │
│         Min: 1x logo height         Min: 1x logo height    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Minimum clear space:** Equal to the height of the logo on all sides

### 2.4 Minimum Size

| Medium | Minimum Size |
|--------|--------------|
| **Digital** | 120px width |
| **Print** | 1 inch width |
| **Icon Only** | 32x32px |

### 2.5 Logo Don'ts

```
❌ Don't stretch or distort
❌ Don't change colors
❌ Don't add effects (shadows, gradients)
❌ Don't rotate or angle
❌ Don't place on busy backgrounds
❌ Don't use outdated versions
```

## 4. Typography

### 4.1 Font Families

#### Primary Font: Inter

Clean, modern, highly readable sans-serif for all UI text.

```
ABCDEFGHIJKLMNOPQRSTUVWXYZ
abcdefghijklmnopqrstuvwxyz
0123456789
!@#$%^&*()
```

**Weights:**
- Regular (400) — Body text
- Medium (500) — Subheadings, buttons
- Semi-bold (600) — Headings
- Bold (700) — Display, emphasis

**Platform Fallbacks:**
- Web: `Inter, system-ui, -apple-system, sans-serif`
- iOS: `SF Pro Text`
- Android: `Roboto`

#### Monospace Font: JetBrains Mono

For code, data, and technical information.

```
ABCDEFGHIJKLMNOPQRSTUVWXYZ
abcdefghijklmnopqrstuvwxyz
0123456789
{[()]} <> /*-+=&|
```

**Usage:** Prices, addresses, hashes, code snippets

## 7. Voice & Tone

### 7.1 Brand Voice

| Attribute | Description | Example |
|-----------|-------------|---------|
| **Professional** | Knowledgeable, credible | "Your portfolio is up 5.2% today." |
| **Approachable** | Friendly, not cold | "Great job! You've saved $125 this month." |
| **Clear** | Simple, direct | "Click 'Trade' to place your order." |
| **Empowering** | Encouraging, positive | "You're contributing to a sustainable future." |

### 7.2 Tone by Context

| Context | Tone | Example |
|---------|------|---------|
| **Success** | Celebratory | "Order filled! 🎉" |
| **Error** | Empathetic, helpful | "Something went wrong. Let's try that again." |
| **Warning** | Clear, urgent | "Low balance. Add funds to continue." |
| **Educational** | Patient, clear | "Here's how P2P trading works..." |
| **Security** | Serious, reassuring | "Your funds are protected with bank-level security." |

### 7.3 Writing Guidelines

#### Do's

✅ Use active voice  
✅ Be concise  
✅ Use contractions (you're, we'll)  
✅ Start with the most important info  
✅ Use plain language  

#### Don'ts

❌ Use jargon without explanation  
❌ Write long paragraphs  
❌ Use passive voice  
❌ Sound robotic or overly formal  
❌ Make assumptions about user knowledge  

### 7.4 Grammar & Mechanics

#### Punctuation

| Element | Style | Example |
|---------|-------|---------|
| **Serial Comma** | Use | "Buy, sell, and trade" |
| **Exclamation Points** | Sparingly | "Success!" (not "Success!!!") |
| **Ellipses** | Avoid | Use clear statements instead |
| **Em Dash** | Use for emphasis | "The result—5% growth—speaks for itself" |

#### Capitalization

| Element | Style | Example |
|---------|-------|---------|
| **Headlines** | Title case | "Trade Energy Instantly" |
| **Body Text** | Sentence case | "Click the button to continue" |
| **Buttons** | Sentence case | "Submit order" |
| **Product Names** | Title case | "GridTokenX Platform" |

#### Numbers

| Context | Format | Example |
|---------|--------|---------|
| **Currency** | Symbol + amount | $1,234.56 |
| **Percentages** | Number + % | 5.2% |
| **Large Numbers** | Abbreviate | 1.5M, 2.3B |
| **Decimals** | 2-8 places | 0.12345678 |
| **Zero** | Use numeral | 0 kWh |

### 7.5 Terminology

| Term | Definition | Usage |
|------|------------|-------|
| **Prosumer** | Energy producer + consumer | "Prosumers can sell excess energy" |
| **GRID Token** | Platform utility token | "Pay with GRID tokens" |
| **P2P Trading** | Peer-to-peer energy trading | "Trade directly with neighbors" |
| **Smart Meter** | IoT energy measurement device | "Connect your smart meter" |
| **REC** | Renewable Energy Certificate | "Trade carbon credits" |
| **Wallet** | Crypto wallet for tokens | "Connect your wallet" |

**Avoid:**
- ❌ "Crypto" → ✅ "Digital tokens"
- ❌ "HODL" → ✅ "Hold"
- ❌ "Gas fees" → ✅ "Transaction fees"
- ❌ "Mining" → ✅ "Validation"

## 9. Layout & Spacing

### 9.1 Spacing Scale

Based on 4px grid system:

| Token | Value | Usage |
|-------|-------|-------|
| **xs** | 4px | Tight spacing |
| **sm** | 8px | Compact spacing |
| **md** | 16px | Default spacing |
| **lg** | 24px | Section spacing |
| **xl** | 32px | Large gaps |
| **2xl** | 48px | Component spacing |
| **3xl** | 64px | Page sections |
| **4xl** | 96px | Major divisions |

### 9.2 Layout Principles

1. **Consistent Margins** — Same spacing throughout
2. **Visual Hierarchy** — More space = more importance
3. **Grouping** — Related items closer together
4. **Breathing Room** — Don't overcrowd

### 9.3 Grid System

**Web:** 12-column grid  
**Mobile:** 4-column grid  
**Gutter:** 16px (mobile), 24px (tablet), 32px (desktop)

| **Ease Out** | cubic-bezier(0, 0, 0.2, 1) | Entering elements |
| **Ease In-Out** | cubic-bezier(0.4, 0, 0.2, 1) | Standard transitions |
| **Spring** | spring(0.5, 300) | Playful interactions |

### 10.3 Animation Principles

1. **Purposeful** — Every animation has a reason
2. **Subtle** — Enhance, don't distract
3. **Performant** — 60fps minimum
4. **Accessible** — Respect reduced motion preferences
